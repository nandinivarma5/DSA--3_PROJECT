Data structures & algorithms used

  • Hash maps (dict / Counter) — word counts, sentiment lexicon, topic tables
  • Sets — O(1) stop-word and vocabulary checks
  • Min/Max heap (heapq) — Top-K keywords and emerging terms
  • Lexicon-based sentiment with negation and intensifier handling
  • Two-window comparison — earlier vs. recent period for trend detection
  • Topic scoring — keyword-overlap classification
